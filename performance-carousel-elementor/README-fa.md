# Performance Image Carousel for Elementor — نسخه 4.1.0

ویجت **«اسلایدر تصویر فوق سبک»** (شناسه ثابت `pce_image_carousel`). به‌روزرسانی مستقیم نسخه‌های قبلی است؛ کلیدهای تنظیمات قبلی حفظ شده‌اند.

## استایل‌ها (محتوا ← «استایل اسلایدر»)
- **کلاسیک (پیش‌فرض):** همان طرح اصلی — یک اسلاید تمام‌عرض، فلش‌های مینیمال سفید، صفحه‌بندی کپسولی سفید با نقطه فعال کشیده نارنجی، دکمه نارنجی با دایره آیکون سفید.
- **بنر حراج:** گوشه‌های گرد ۴۰px، بریدگی وسط بالای بنر، صفحه‌بندی شیشه‌ای، دکمه شیشه‌ای دورخط با فلش، چیدمان متن: متن کوچک ← توضیح ← تیتر درشت ← زیرتیتر ← دکمه.
- **بنر لوکس:** گوشه ۵۲px، بریدگی پهن‌تر، تیتر و زیرتیتر با خط کناری، متن کوچک با نوار، دکمه سرمه‌ای با سایه.
- **تمام‌عرض (مدل دیجی‌کالا):** بدون گوشه، نسبت 24:5، متن تیره، دکمه کپسولی تیره کوچک، نقطه‌های سفید ریز، فلش‌ها فقط با هاور.

رنگ بریدگی باید هم‌رنگ پس‌زمینه سکشن باشد (پیش‌فرض سفید) — از همان بخش قابل تغییر است، همراه با عرض، عمق و گردی آن.
همه رنگ‌ها، اندازه‌ها، تایپوگرافی و فاصله‌ها از تب «استایل» قابل تغییرند؛ استایل فقط مقدار پیش‌فرض را عوض می‌کند.

## فیلدهای هر اسلاید
تصویر دسکتاپ، تصویر موبایل، متن کوچک بالای تیتر (با `<b>` برای عدد درشت، مثل `تخفیف تا <b>15%</b>`)، تیتر، زیرتیتر، توضیح، متن دکمه، لینک، جایگاه متن و رنگ‌های اختصاصی.

## پرفورمنس
- Vanilla JS، یک فایل حدود 9KB (≈3.6KB gzip)، بدون jQuery و Swiper. یک فایل CSS.
- تصاویر داخل HTML با `<img>` + `srcset` + `sizes` + width/height (بدون CLS). با «تصویر موبایل» از `<picture>` استفاده می‌شود و موبایل فقط فایل موبایل را دانلود می‌کند؛ نسبت قاب موبایل هم خودکار از همان تصویر گرفته می‌شود.
- تصویر اول `eager` + `fetchpriority=high`؛ بقیه lazy و بعد از لود صفحه، فقط اسلایدهای مجاور پیش‌بارگذاری می‌شوند.
- «حداکثر عرض نمایش» (مثلاً 1270) باعث می‌شود مرورگر فایل کوچک‌تری از srcset بگیرد.
- حرکت خودکار وقتی اسلایدر خارج از دید است، تب مخفی است یا کاربر هاور/فوکوس کرده متوقف می‌شود. `prefers-reduced-motion` رعایت می‌شود.
- انیمیشن ورود متن روی اسلاید اول اجرا نمی‌شود تا LCP دیر نشود.

## نکته ارتقا
پیش‌فرض‌های v4: تعداد اسلاید 1، ارتفاع با نسبت تصویر، فلش مینیمال سفید. ویجتی که روی پیش‌فرض‌های نسخه 3 (۱.۲۵ اسلاید / ارتفاع ۴۵۵px) مانده بود ظاهرش عوض می‌شود؛ برای حالت قبلی: «روش تعیین ارتفاع ← ارتفاع ثابت» و «تعداد اسلاید ← 1.25».
افکت‌ها و شکل‌های نسخه 4.0 حذف شده‌اند؛ ویجتی که با آن‌ها ذخیره شده بود به اسلاید کلاسیک برمی‌گردد.

بعد از ارتقا: Elementor → Tools → Regenerate CSS & Data و پاک کردن کش WoodMart/CDN. ابتدا روی Staging تست شود.

## توسعه
سورس خوانا در `assets/src/` است:
```
esbuild assets/src/carousel.js --minify --target=es2019 --outfile=assets/carousel.min.js
esbuild assets/src/carousel.css --minify --outfile=assets/carousel.min.css
```
برای محتوای Ajax: `window.PCECarousel.init(element)`.
